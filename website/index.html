Get Started

AI-native observability and security for engineering teams and coding agents

Quickstart: https://github.com/j4yop/docket#readme

Get started: npx @docket/cli start

Docket is an AI-native observability and security platform for teams that ship software quickly. It connects production logs with code, detects important issues without hand-built monitors, investigates root causes, and sends useful context to the tools where engineers work. Ask questions in plain language, understand what changed, and let coding agents use that context to help resolve production problems.

Use Docket for autonomous alerts, conversational debugging, and coding agent workflows. Docket is built for engineering teams that need to find and fix production issues without maintaining a large collection of dashboards and static monitors. Explore the product, integrations, security practices, and developer resources to learn how Docket fits your stack.
