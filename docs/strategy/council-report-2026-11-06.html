Clocked Build Challenge · Council verdict · 2026-11-06

Docket should win on proof, not on nine endpoints.

The product is technically strong enough to win Best Overall. The gap is that a judge meets an API harness before meeting the product. This report ranks the fixes by the official rubric and gives a four-day plan.

Verdict. Reposition Docket as the release gate for AI answers that must be defensible: it proves which policy governs, blocks release when evidence does not hold, and leaves a replayable audit record. Use /tour as the submission demo, not the marketing page. Lead with zero unsafe false-PUBLISH, not 25/31 or 27/31.
Practical usefulness · 25Real policy-sprawl pain, but no single buyer and no flagship first-run path. Fix with one buyer, one sentence and one France case.
Core integration · 30All nine endpoints decide. The proof is buried. Show each endpoint's effect and a Clocked-off fail-closed test.
Additional endpoints · 15All nine wired, but breadth looks like checkboxes unless each one has a visible consequence.
Implementation / UX · 2092 tests, ledger, health, review queue. The judge path must be one click and never lie about partial runs.
Clarity / reproducibility · 10Deep README, but judges need a one-page JUDGES.md, a 2-minute video and three commands.

The four-day plan

Nov 6 · Judge path

  • Submit /tour, not /.
  • One click, 8 rows, 8/8, under 30s.
  • Partial runs say Incomplete and retry only failed cases.
  • 60/hour demo budget; fallback video.
  • Prominent Judge tour button in console.

Nov 7 · Core loop

  • One-line buyer and value proposition.
  • Run the flagship France case in one click.
  • Verdict, governing quote, review state first.
  • Plain-language definitions for jargon.
  • Do not touch the marketing page.

Nov 8 · Proof + robustness

  • Endpoint necessity table and ablation proof.
  • Clocked-off negative control: HOLD, never PUBLISH.
  • 10-case adversarial suite; publish zero unsafe PUBLISH.
  • Fix the two real no_governing_clause failures as post-tuning.

Nov 9 · Freeze

  • Write the entry form around the rubric.
  • Select Best Overall and all three group awards.
  • Record the 2-minute demo.
  • Tests, deploy, incognito smoke test.
  • No new features after Nov 9.

The 2-minute demo

  1. Problem: an AI answer is fluent, cited and wrong because it used a superseded policy.
  2. Tour: eight cases in one click — precedence, version, omission, clean, injection, runbook, unapproved, tampered.
  3. Precedence: France annex overrides newer global policy; show superseded value and governing quote.
  4. Safety: injection and unsafe runbook HOLD; nothing ships.
  5. Audit: review record plus hash-chained ledger; human release/send-back is recorded.
  6. Why nine: decision endpoints decide; safety endpoints protect; Extract/Decide preserve metadata and triage. Disable them and the gate fails closed.
  7. Honest close: 25/31 locked, 27/31 post-tuning, zero unsafe false-PUBLISH, failures published.

What not to do

  • No Slack/Zendesk/multi-tenant/replay product in four days.
  • No public admin bypass; keep the admin boundary and show the evidence.
  • No editing locked held-out cases or presenting post-tuning as locked.
  • No headline 25/31 or 27/31; headline zero unsafe false-PUBLISH.
  • No more endpoints or cases. The bottleneck is clarity and reliability.
