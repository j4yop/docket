    How the decision is made
    
        
    Three model judgments, one rule engine, and a verdict you can defend.
    
      
    
      
    
        
    
          01
          
    Authority is a rule
    
          
    Jurisdiction, precedence and effective date pick the governing document. A tie becomes Hold; the app never asks a model which policy wins.
    
        
    
        
    
          02
          
    Rerank selects the clause
    
          
    The governing rule is passed in the instructions. Rerank returns use, expand or skip for every candidate clause, with a reason.
    
        
    
        
    
          03
          
    Compare shows the conflict
    
          
    Only the governing and superseded clauses are compared. Short, aligned passages are where Compare is accurate and cheap; whole documents are not.
    
        
    
        
    
          04
          
    Verify decides
    
          
    Every counted claim in the draft is marked supported, contradicted or not stated. One bad claim is enough to force a rewrite.
    
        
    
      
    
      
    
        
    
          
    Use it from an agent
    
          
    The same gate is a JSON endpoint. An assistant calls it before it sends an answer.
    
        
    
        
    curl -s https://your-deploy/api/check \
  -H 'Content-Type: application/json' \
  -d '{"question":"…","draft":"…",
       "documents":[…]}'
